A one-line office joke for the [One-Line Office Joke Laugh-Off](https://make.fun/bounty/u-suzy-one-line-office-joke-laugh-off-f574ac73) bounty on make.fun.

## The joke

> HR says the office plants boost morale, so now the ficus has a promotion plan and I'm getting feedback from a fern.

## How to run

```sh
node main.ts
```

This writes the joke to `/output/entry.txt`. The program validates the entry
first: it must be a single line of 1–200 characters, otherwise it throws
instead of writing anything.
